# Users, Roles, and Access

Choreo Integration gives you centralized control over who can access your organization and projects, what actions they can perform, and how they authenticate. You can define granular permissions using roles and groups and enforce organization-wide policies.

## Access control

The platform uses two building blocks to control access:

| Concept | Description |
|---|---|
| **Role** | A collection of permissions. The platform ships with a predefined set of roles. |
| **Group** | A collection of users. Assign one or more roles to a group so its members inherit the corresponding permissions. |

Authorization works by assigning one or more roles to a group.

## User Portal

The User Portal is a separate portal that exposes your integrations to external users. After you enable it for your organization, you can publish AI agents and automations to it. Users sign in through your Choreo Identity organization and can chat with agents and run automations without access to the Choreo Cloud console. You manage User Portal users and roles, and the permissions of each role, from the Choreo Cloud console.
