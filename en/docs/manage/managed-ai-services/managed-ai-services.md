# Managed AI Services

WSO2 Cloud - Integration Platform provides managed services for building AI-powered integrations. You can let users talk to a deployed AI agent by voice. WSO2 Cloud provisions and operates these services, so you don't manage the underlying infrastructure.

## Available services

| Service | Use it to |
| --- | --- |
| [Voice Agents](./voice-agents.md) | Add a voice pipeline in front of a deployed AI agent, using LiveKit with speech-to-text and text-to-speech providers. |
