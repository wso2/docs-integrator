# Pricing and Plans

WSO2 Cloud bills the platform services you create, such as databases, caches, or Kafka services, as part of your existing subscription. The cost depends on the service plan and the usage of each resource.

## Platform service billing information

- **Hourly billing**: Usage is billed based on the number of hours a resource is active. For example, if you create a database, cache, or Kafka service and remove it within the same month, you pay only for the hours it was active.
- **Fixed pricing**: Pricing is based on the selected service plan. WSO2 Cloud does not charge extra for network bandwidth usage.
- **Plan limits**: Each subscription plan has its own quotas for builds, deployments, infrastructure, logs, and other resources. See [Acceptable Usage Policy](./acceptable-usage-policy.md) for the full per-plan breakdown.

## Upgrade a service plan

If you want to upgrade the service plan of a platform service you have created, contact [WSO2 Cloud support](mailto:devant-support@wso2.com).
