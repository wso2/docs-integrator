# Observe

Observability is how you understand what an integration is actually doing in production, using its runtime logs.

Runtime logs answer *"why is it behaving this way?"* They explain what is happening inside a deployed integration, which is what you need for problems you did not anticipate.

Choreo Integration provides a built-in observability dashboard, so there's nothing to set up.
