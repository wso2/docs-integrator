# Integration Runtime Updates and Upgrades

## Availability of latest runtime

The latest integration runtime released by WSO2 is always available to Subscriber through the Integration Platform SaaS.

## Optional upgrades

Use of the latest integration runtime version is optional. Subscriber may:

- Test any integration runtime that is currently supported by WSO2 before deploying it in production; and
- Choose whether and when to upgrade existing integration services from older runtimes to newer runtimes.

## Supported versions

WSO2 will provide information about currently supported integration runtime versions at the [WSO2 support matrix](https://wso2.com/products/support-matrix/). Subscriber is responsible for ensuring that production deployments use supported runtime versions.
