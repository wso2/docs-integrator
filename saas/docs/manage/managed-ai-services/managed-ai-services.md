# Managed AI Services

WSO2 Cloud - Integration Platform provides managed services for building AI-powered integrations. You can give AI agents and integrations access to your organization's content through retrieval-augmented generation (RAG), store embeddings in managed vector databases, and let users talk to a deployed AI agent by voice. WSO2 Cloud provisions and operates these services, so you don't manage the underlying infrastructure.

## Available services

| Service | Use it to |
| --- | --- |
| [Knowledge Bases](./knowledge-bases/knowledge-bases.md) | Index content from Google Drive or Amazon S3 and retrieve the most relevant chunks for RAG through a managed Knowledge Base service. |
| [Vector Databases](./vector-databases.md) | Provision managed PostgreSQL vector databases for vector similarity search on AWS, Azure, GCP, or DigitalOcean. |
| [Voice Agents](./voice-agents.md) | Add a voice pipeline in front of a deployed AI agent, using LiveKit with speech-to-text and text-to-speech providers. |
