Actions

The DocuSign Admin connector exposes the following clients:

ClientPurpose
ClientManage organizations, users, permissions, groups, DSGroups, product permission profiles, bulk user imports, account settings exports and imports, and asset groups through the DocuSign Admin API.

Client​

The Client connects to the DocuSign Admin API (https://api.docusign.net/Management). It exposes 58 operations as resource functions; each is listed by its HTTP method and resource path.

Initializing the client​

import ballerinax/docusign.dsadmin;

configurable string clientId = ?;
configurable string clientSecret = ?;
configurable string refreshToken = ?;
configurable string refreshUrl = ?;

final dsadmin:Client dsadminClient = check new ({
    auth: {
        clientId,
        clientSecret,
        refreshToken,
        refreshUrl
    }
});

Organizations​

List organizations

Returns a list of organizations that the authenticated user belongs to.

Resource: get v2/organizations

Parameters:

NameTypeRequiredDescription
headersmap<string|string[]>NoHeaders to be sent with the request. Defaults to {}.
modestringNoSpecifies how to select the organizations. Valid values: - org_admin: Returns organizations for which the authenticated user is an admin. - account_membership: Returns organizations that contain an account of which the authenticated user is a member Default value: org_admin.

Returns: OrganizationsResponse|error

Sample code:

dsadmin:OrganizationsResponse result = check dsadminClient->/v2/organizations.get();
