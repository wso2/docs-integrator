Actions

The Microsoft Outlook Mail connector exposes the following clients:

ClientPurpose
ClientSend, receive, organize, and manage email messages, mail folders, and attachments for the signed-in user and any user in a Microsoft 365 tenant via the Microsoft Graph API

Client​

The Client connects to the Microsoft Graph API v1.0 to manage email messages, attachments, and mail folders for the signed-in user and for any user in a Microsoft 365 tenant.

Retrieves the signed-in user's messages from the default mailbox, supporting OData query parameters to filter, sort, search, and project the result set.

Parameters:

NameTypeRequiredDescription
headersmap<string|string[]>NoHeaders to be sent with the request
dollarSkipintNoSkip the first n items
dollarTopintNoShow only the first n items

dollarSearchstringNoSearch items by search phrases
dollarOrderbystring[]NoOrder items by property values
dollarExpandstring[]NoExpand related entities
dollarCountbooleanNoInclude count of items
dollarSelectstring[]NoSelect properties to be returned
includeHiddenMessagesbooleanNoInclude hidden messages

Returns: MicrosoftGraphMessageCollectionResponse|error

Sample code:

mail:MicrosoftGraphMessageCollectionResponse result = check mailClient->listMessages(
