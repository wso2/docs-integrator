WSO2 Integrator on AWS

WSO2 Integrator provides support for building, deploying, securing, and observing integrations on Amazon Web Services (AWS). You can connect to AWS services, use Amazon Bedrock for AI capabilities, deploy integrations on AWS compute services, securely access AWS resources using IAM roles, and monitor integrations using AWS observability services. This page provides an overview of the capabilities and resources available for using WSO2 Integrator with AWS.

New to AWS?​

Here are four AWS concepts you'll see throughout this guide

ECS

A fully managed container orchestration service for running your integration, used by the recommended deployment below.

IAM role

An identity AWS gives your integration, so it can use AWS without access keys in your code.

VPC

An isolated virtual network within AWS where you run and connect your resources.

Amazon Bedrock

The AWS service for using AI models from several providers through one API.

Secure on AWS​

Follow these three practices from day one.

Use IAM roles, not keys

Your integration picks up the role of wherever it runs - nothing secret lives in code.

Default credential chainAttach an IAM roleCross-account access

Keep secrets out of code

Load passwords and settings from AWS Secrets Manager or SSM Parameter Store.

Keep traffic private

Reach AWS services through VPC endpoints, with FIPS and dual-stack options.
